## 3. Implementation decisions

- **Engine is pure TypeScript** (no DOM) so it is unit-testable in Node.
- **Overlap resolution:** precedence first (CARD > AADHAAR > PAN > EMAIL > IPV6 > IPV4 > PHONE), then
  length, then position. Numeric patterns use lookarounds that refuse to match next to `@`, `.`, word
  characters, or adjacent digit groups, so digits are never carved out of emails or longer numbers.
- **Rejections:** non-Luhn 13–19 digit candidates (and Verhoeff failures when enabled) are recorded, shown
  with a dashed amber underline, counted, and left unchanged. Rejections overlapped by an accepted match are dropped.
- **IPv6:** a loose candidate regex followed by structural validation, so timestamps (`10:42:13`) and
  `std::vector` are not matched.
- **Pseudonyms:** fresh `Map` per run, keyed by normalized value (lower-cased email, digits-only
  card/Aadhaar, national number for phones, expanded IPv6). IPv4 and IPv6 share the `IP_` counter.
- **Category filters:** disabled categories still claim their span (so they are not re-detected as something
  else) and are counted, but are not replaced.
- **CSV:** deviation from the plan: no cell-level tokenizer is needed. Patterns cannot cross delimiters or
  line breaks and replacements contain none, so structure is preserved by construction.
  `src/utils/csv.ts` only detects the delimiter, describes rows/columns, and verifies the structure
  skeleton is unchanged. Line endings: textarea normalizes to LF, so the original ending is restored on edit.
- **Privacy:** CSP `connect-src 'none'` in `index.html` and `vercel.json`; no external fonts or scripts.
- Synthetic sample data only (public test card numbers, made-up identifiers).

## 4. UX polish pass

Request: clearer first-run experience, clearer control wording/tooltips, obvious export, and a "How it works"
section.

- **Empty states:** a shared `EmptyState` component. The input panel shows guidance plus *Try the sample
  log / CSV* buttons over the textarea (the overlay passes clicks through to the textarea). The Source pane
  repeats the sample buttons; the Sanitized pane explains what will appear. Panes return to normal as soon as
  there is text.
- **Controls:** numbered steps (1 add text, 2 choose how to redact, 3 copy/download). Tooltips explain Full,
  Partial, Pseudonymize ("stable token, restarts every run, nothing saved"), "Label what was removed" (typed
  tags, Full mask only) and the Aadhaar Verhoeff check (off by default so typos are still redacted). A live
  one-line summary under the controls describes the active mode.
- **Export:** moved into its own card with larger Copy and Download buttons, a status line, and a visible
  message if the clipboard is blocked.
- **How it works:** supported-formats table, Luhn false-positive explanation (~9 in 10 random 16-digit
  numbers fail Luhn; a rare Luhn-valid ID is still redacted, the safe direction), precedence order, and a
  three-mode example. The example outputs are generated by `sanitize()` at render time and asserted in
  `piiEngine.test.ts`, so the text cannot drift from behaviour.

## 5. Dark mode and motion

Request: add dark mode and make the site much more animated, with its use cases.

- **Dark mode:** a `.dark` class on `<html>` remaps Tailwind's color variables (`src/dark-theme.css`, generated
  from `tailwindcss/theme.css`: slate re-tuned by hand so panels, hovers and borders stay distinct; accent
  scales inverted). Every existing `bg-/text-/border-` class flips with no per-component `dark:` variants.
  `public/theme-init.js` is loaded synchronously from `<head>` (external, so the CSP `script-src 'self'` still
  holds) to apply the saved/system theme before paint. A brief `theme-fade` class cross-fades the switch.
- **Motion:** CSS keyframes in `index.css` (fade-up, mark-in, float, pop) and a `press` utility; small
  components `Reveal` (IntersectionObserver scroll-reveal), `AnimatedNumber` (count-up) and a sliding pill in
  `ControlsBar`. Output highlights replay a staggered glow when mode/options change (keyed by settings so the
  pane's scroll position is kept). Highlight animation avoids `transform` because `<mark>` is inline.
- **Use cases:** `UseCases` replaces the old banner: four cards plus `RedactionDemo`, an auto-playing tabbed
  before/after built from the real engine (clicking a tab pauses it).
- **Accessibility:** `prefers-reduced-motion` collapses all animation/transition durations and stops the demo
  auto-play. No animation library or network request was added.

## 6. Globe entry intro

Request: a dismissible, strictly client-side revolving-globe entry experience with regional leak scenarios,
a value-proposition overlay, Skip/Esc, session persistence and a header "Replay Intro".

- **Rendering:** `src/utils/globe.ts` holds the pure maths (orthographic projection, shortest-angle easing,
  point-in-polygon, land-dot sampling) so it is unit-tested in Node (`globe.test.ts`). `GlobeIntro.tsx` draws
  it on a 2D canvas: atmosphere glow, shaded sphere, graticule that breaks behind the limb, ~1k land dots
  that fade toward the edge, and pulsing pins. No WebGL, three.js, tiles or fetched data; bundle grew ~5 kB gzip.
- **Land data:** ten coarse continent polygons written by hand (recognisable as dots, not cartography).
  A test asserts known land/ocean points and that all six hotspot cities fall on land.
- **Scenarios:** India (Bengaluru/Mumbai), North America (San Francisco/New York), Europe (Frankfurt/London),
  each with the leak and the outcome from the brief. The camera eases to each region (taking the short way
  round) with a slow sway so it always feels like it is revolving. They are labelled illustrative, not incidents.
- **Dismissal/persistence:** Skip, Launch and Esc all close it; `sessionStorage` (try/catch) remembers it for
  the session; Replay Intro reopens it and focus returns to the opener.
- **Accessibility:** `role="dialog"` + `aria-modal`, focus moved to the primary button and trapped, the
  workspace is `inert` while open, scenarios are real tabs (clicking one stops auto-advance), and under
  `prefers-reduced-motion` the globe is a static frame that redraws only on change.
- **Privacy check:** source scan found no network APIs or URLs. The production bundle had exactly one
  `fetch(`, from Vite's modulepreload polyfill (same-origin only, and no modulepreload links exist), so it was
  disabled (`build.modulePreload.polyfill = false`); the bundle now has none. CSP `connect-src 'none'` is unchanged.
  This is a static check; I did not capture a DevTools Network panel.
- The intro uses fixed hex colours rather than theme tokens so it looks the same in light and dark mode
  (dark mode remaps Tailwind's named colours).

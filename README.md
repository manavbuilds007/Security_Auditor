# PII Sanitizer

A 100% client-side tool that finds and redacts personally identifiable information in text and CSV files.
Everything runs in your browser; there is no backend, no analytics and no network calls (the page ships a
CSP with `connect-src 'none'`, and the production bundle contains no `fetch`, XHR, WebSocket or beacon calls).

Stack: Vite · React · TypeScript · Tailwind CSS · lucide-react · Vitest.

## Features

- **Input:** paste text, or upload `.txt` / `.csv` (read with `FileReader`; delimiters, rows and line endings are preserved). One-click sample log and sample CSV.
- **Detection:** emails, Indian/international phones, IPv4 (octets 0–255), IPv6, Indian PAN, Aadhaar (12 digits, not starting with 0/1, optional Verhoeff checksum), and 13–19 digit credit cards validated with Luhn.
- **Overlaps:** resolved by precedence `CARD > AADHAAR > PAN > EMAIL > IPV6 > IPV4 > PHONE`, then length.
- **Rejected false positives:** card-shaped numbers that fail Luhn (and, if enabled, Aadhaar that fail Verhoeff) are left untouched and counted.
- **Modes (live toggle):**
  - Full mask: `[REDACTED]` or typed `[REDACTED_EMAIL]`
  - Partial mask: `j***@domain.com`, `XXXX-XXXX-XXXX-1234`, `XXXXX1234X`, `+91-XXXXXX3210`, `192.168.XXX.XXX`
  - Consistent pseudonyms: `USER_01`, `CARD_01`, `PAN_01`, `AADHAAR_01`, `PHONE_01`, `IP_01` (same normalized value → same token, per run)
- **Entry intro:** a full-screen interactive globe drawn with pure `<canvas>` 2D orthographic projection (continents are coarse hand-written polygons, so no map tiles, GeoJSON, textures or WebGL). Graphics: dotted land with crisp coastlines, graticule, atmosphere rim and halo, a lit side and terminator, parallax stars, an orbiting ring with a satellite, and animated great-circle **leak arcs** with data packets that turn green when the leak is blocked. Pins pulse through three illustrative scenarios (India, North America, Europe) next to a Raw Document → In-Browser Scrubbing → Safe to Share flow.
  - **Cursor:** the globe is lit from your cursor (with a spotlight) and leans toward it; **drag to rotate** with inertia, after which it drifts back to the scenario; hover a pin for a tooltip and click it to jump to that scenario.
  - **Leaving:** **Skip to Sanitizer →**, **Launch Sanitizer** or `Esc`; remembered per browser session (`sessionStorage`), and **Replay Intro** in the header brings it back. With reduced-motion enabled nothing moves on its own: the globe is a static frame that only redraws when you interact, and scenarios are changed with the tabs.
- **Dark mode:** toggle in the header; follows your system setting on first visit and remembers your choice (`localStorage`, applied by `public/theme-init.js` before first paint so there is no flash).
- **Motion:** staggered scroll-reveal, sliding mode selector, count-up audit numbers, highlight glow when redactions are (re)applied, press feedback on buttons, and a looping before/after demo. Pure CSS plus tiny hooks (no animation library), and all of it is disabled under `prefers-reduced-motion`.
- **Use cases:** a header section (LLM prompts, vendor handoff, CSV sharing, public bug reports) with a live Original → Full → Partial → Pseudonymize demo generated by the real engine.
- **Guidance:** friendly empty states (with one-click sample log/CSV buttons in the input and Source panes), plain-language tooltips on every control, and a "How it works & supported PII" section whose examples are generated by the real engine and pinned by a test.
- **Review:** side-by-side source/sanitized view with colored highlights and tooltips, category on/off filters with counts, audit summary bar.
- **Export:** a prominent step-3 card with *Copy sanitized text* and *Download `<name>_sanitized.<ext>`* (disabled until there is output; explains itself if the browser blocks clipboard access).

## CSV handling

No detection pattern can span a delimiter, quote or line break, and no replacement token contains one, so
structure is preserved by construction. For `.csv` files the summary bar verifies this on every run by
comparing the delimiter/quote/newline skeleton of input and output.

Note: browsers normalize line breaks inside `<textarea>`; the app restores the uploaded file's original line
ending (e.g. CRLF) when you edit.

## Develop

```bash
npm install
npm run dev          # http://localhost:5173
npx vitest run       # unit tests
npx tsc --noEmit -p tsconfig.app.json
npm run build        # outputs dist/
```

## Deploy

**GitHub**

```bash
git remote add origin https://github.com/<you>/<repo>.git
git push -u origin main
```

**Vercel:** import the repo at <https://vercel.com/new>. The framework is auto-detected as Vite; `vercel.json`
sets the build output and security headers (CSP, `nosniff`, `no-referrer`).

## Limits

Pattern-based detection is not exhaustive: it does not find names, addresses, or free-form identifiers, and
phone/number heuristics can produce false positives or negatives. Review the output before sharing it.
